Additional useful captures for a future expanded gallery are:

1. `campaign-architect.html` — shared decision-simulator experience

3. A mobile hub capture when responsive behavior materially changes

Use a desktop viewport and capture the first meaningful working state, not a loading screen. Add a second mobile capture only when it demonstrates a materially different responsive interaction. Keep filenames stable and descriptive so README links survive future recaptures.
