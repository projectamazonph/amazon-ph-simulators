// Operating Principles

how the Academy trains
// 01
Real fidelity, not a demo Every tool mirrors the production Amazon console. Layout, copy, controls — what the VA sees on the job, they'll see here first.
// 02
Drill, don't read Reading docs doesn't make a PPC operator. The simulators are the homework. Read once, drill until it's muscle memory.
// 03
Honest feedback Every drill returns a verdict — a grade, a coach note, a what-would-you-do-next. No participation trophies.
// 04
Operator vocabulary Campaigns, ad groups, match types, day-parting, ACoS, TACoS, search-term harvest — the words the job uses, the words we teach.
